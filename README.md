# 🌿 AyurGuard – Ayurvedic Wellness & Consultation Platform

AyurGuard is a modern web application designed to bridge traditional Ayurvedic healthcare with modern digital solutions.

🚀 **Live Demo:** [https://ayurveda-diagnosis-and-recommendati.vercel.app/](https://ayurveda-diagnosis-and-recommendati.vercel.app/)

---

## ✨ Key Features

* **Interactive Prakriti Analysis Tool:** Rule-based algorithm to assess Vata, Pitta, and Kapha body types.
* **Symptom Questionnaire:** Interactive diagnosis tool based on Ayurvedic principles.
* **Telemedicine & Doctor Booking:** Easy consultation requesting system.
* **Online Herbal Shop:** Dynamic shopping cart with herbal product catalogue.
* **Theme Customization:** Seamless Dark / Light mode switching with forest aesthetic.

---

## 🛠️ Tech Stack

* **Frontend:** React.js, Tailwind CSS / CSS Modules
* **Backend:** Node.js, Express.js
* **Database:** MySQL
* **Deployment:** Vercel (Frontend)
